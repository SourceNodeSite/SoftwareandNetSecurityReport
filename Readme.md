# 须知 
## 本项目旨在收集和整理国内重大软件和网络安全事件

> "本项目为非盈利开源项目，由社区维护。"

> [!INFO]
> 引言：信息及大数据时代，软件工程和互联网安全日渐重要，根据知名漏洞库CVE整合，2026年的CVE数量确实显著多于往年，且这一增长趋势在年中被进一步上调，创下了历史记录。基于此创建此数据库以整合由底层漏洞或其他普适性问题导致的事故或事件供开发者参考

> [!WARNING]
> 注意：提交内容的所有内容请遵守Rules文件中的规范，本数据库仅供参考，具体请以实际为准

## 内容
一切有关于重大[^1]软件和网络安全的事件
## 贡献方式
1. 提供线索（仅限有效线索）
2. 撰写报告（仅限被采纳的提交）
3. 协助审阅
4. 修正问题（问题被验证为可信）
5. 为仓库机制提供代码支持
   
## 加入审阅的条件
至少发布过1-3篇通过的报告或提出5-10个问题并被采纳或提出3-5个被判定为有用的线索，或有权威性的认证文件（证明专业性）和其他可以证明专业性的资料，需要申请，在没有被警告，
## 我们的宗旨
以客观严谨的态度分析和探讨事件的本质问题
